# Aplicabilidade da transferência — GitHub

- **Destino**: Estados Unidos e outros países/subprocessadores publicados pelo GitHub.
- **Dados**: IP/logs de Pages; identidade, e-mail e metadados de contribuidores.
- **Finalidade/base**: hospedagem, segurança e colaboração; legítimo interesse (LGPD, art. 7º, IX).
- **Classificação atual**: logs de visitantes do Pages são coleta direta do GitHub e não transferência automática pelo app (Res. 19/2024, art. 6º). Dados de contribuidores enviados ou mantidos pelo responsável podem configurar fluxo controlador–importador, conforme papéis e plano.
- **Mecanismo**: para eventual transferência de dados de contribuidores, confirmar cobertura do produto/conta pelo DPA e pelo mecanismo brasileiro aplicável; SCCs europeias não foram presumidas equivalentes às cláusulas brasileiras.
- **Risco**: médio.
- **Decisão**: aprovado com ressalvas no projeto pessoal; publicar transparência e confirmar plano/papel/mecanismo somente para operações que de fato caracterizem transferência.
